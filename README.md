# 🩷 Happy Birthday Jenifah! 🩷

A beautiful, interactive neon-style birthday website dedicated to Jenifah.

## ✨ Features

- 🌟 **Neon Glowing Text** - Flickering cyan and pink text with glow effects
- 💝 **Falling Hearts Animation** - Continuous falling hearts in the background
- 🎉 **Celebration Effects** - Click the surprise button for confetti and wishes
- 🎂 **Animated Cake** - Bouncing birthday cake with candles
- 🎈 **Floating Emojis** - Balloons, gifts, and sparkles floating around
- 📱 **Responsive Design** - Works on all devices (mobile, tablet, desktop)
- 🎨 **Beautiful Color Scheme** - Neon cyan, pink, and dark background

## How to Use

1. Open `index.html` in your web browser
2. Click the "Click for Surprise! 🎉" button for instant celebration
3. Press SPACEBAR for quick celebrations
4. Watch as hearts, confetti, and wishes appear!
5. Automatic celebrations happen every 12 seconds

## Files

- `index.html` - Main HTML structure
- `style.css` - All styling and animations
- `script.js` - Interactive effects and celebrations
- `README.md` - This file

## Customization

You can customize:
- **Colors**: Modify color values in `style.css`
- **Messages**: Update wishes in `script.js`
- **Emojis**: Change emoji selections
- **Animation speeds**: Adjust animation durations

## Technologies Used

- HTML5
- CSS3 (Animations & Effects)
- Vanilla JavaScript
